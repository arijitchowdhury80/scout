## Launch-Day Thread (9 posts)

**1/**
I built Scout because I was tired of copy-pasting websites into a doc and losing track of where anything came from.

Scout turns any web page into a clean record you can actually cite. Live today on Product Hunt.

scout.chowmes.com

**2/**
The problem: most scraping tools hand you a wall of text. A blob.

You still have to read it, clean it, and figure out which fact came from which page.

By the time you're done, you've done the work the tool was supposed to do.

**3/**
Scout gives you records, not blobs.

Point it at a company site and you get the company details, the people, the open roles, the funding history, the recent news. Each field sitting where you expect it, with the page it came from attached.

**4/**
Every fact keeps its source.

So when you drop it into a report, a pitch, or a model, you can show your work. That is the whole idea behind "evidence-grade." Nothing floating without a link back to where it lives.

**5/**
It does the boring web jobs too:
- read one page
- crawl a whole site
- map every URL on a domain
- grab a full-page screenshot
- pull product catalogs into search-ready records

One tool for the stuff you keep writing throwaway scripts for.

**6/**
Product people: it turns a messy store into clean product records, ready to load straight into Algolia. Titles, prices, images, variants, all lined up.

I use it to build demo catalogs in minutes instead of an afternoon.

**7/**
Two ways to use it.

A simple web API you can call from anything.

And a skill that plugs straight into Claude and Codex, so your AI assistant can go read the web and bring back real records instead of guesses.

**8/**
This is a beta. I want 50 to 100 people who actually crawl the web for a living to break it and tell me where it hurts.

If that is you, grab a spot. Honest feedback is the whole point. I would rather hear what's wrong now than after launch.
