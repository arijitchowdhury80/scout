# TikTok / Reels Scripts

Voice: plain, sharp, founder on camera or voiceover. No em dashes. No hype.
Rule: do not fabricate timings on screen. Beats below are directional.

---

## Script 1: "Watch it turn a messy site into clean records" (about 30s)

**Hook (first 2 seconds, on camera or screen):**
"This website is a mess. Watch me turn it into something I can actually use."

**On-screen text beats:**
- 0:00 "Every scraper gives you a wall of text."
- 0:06 "I wanted records instead."
- 0:12 "One command. One website."
- 0:18 "Company. People. Jobs. News."
- 0:24 "And the source stays attached to every fact."
- 0:28 "Scout. scout.chowmes.com"

**Voiceover:**
"Here's a company site. Cluttered, slow, half of it behind menus. I run Scout on it. A few seconds later I've got the company details, the team, the open roles, and the recent news, each one lined up in its own field. And every single fact still points back to the page it came from. That's the part that matters. I'm not copying a blob and hoping. I've got records I can cite. Link in bio."

**Shot list:**
1. Screen recording: the messy target website, scrolling fast.
2. Cut to a terminal or the Scout web tool, hit run.
3. Screen recording: the clean result filling in, field by field.
4. Zoom on one field showing the source link next to it.
5. End card: Scout logo, URL, "Beta open now."

## Script 2: Founder story (about 35s)

**Hook (first 2 seconds, founder on camera):**
"I built this because I kept lying to myself in reports."

**On-screen text beats:**
- 0:00 "I kept using facts I couldn't source."
- 0:07 "Pulled from sites weeks ago."
- 0:13 "No idea which page anymore."
- 0:20 "So I built a tool that never lets that happen."
- 0:28 "Records, with the source attached."
- 0:33 "Scout. Beta open now."

**Voiceover:**
"Every research doc I wrote had the same weak spot. Facts I'd grabbed off some website, and by the time anyone asked where it came from, I couldn't tell them. That's not research. That's guessing with confidence. So I built Scout. You point it at any website and it hands back clean records, and every fact keeps a link to the exact page it lives on. Now when someone asks how I know, I can show them. It's in beta. I'm looking for people to break it and tell me the truth. Link in bio."

**Shot list:**
1. Founder talking to camera, plain room, no set dressing.
2. B-roll: a report on screen with a highlighted claim and a question mark over it.
3. Cut back to founder.
4. Screen recording: Scout result with the source link visible.
5. End card: founder face, URL, "Tell me what's broken."
